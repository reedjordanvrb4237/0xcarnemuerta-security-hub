## Overview

The 0xcarnemuerta Security Portfolio is a web-based collection of security-focused data and machine-learning engineering work. Alongside portfolio material, it publishes technical discussions about the real-world security problems found in contemporary data and AI environments.

The content is aimed at engineers, security professionals, and anyone investigating areas such as prompt injection, token-based authentication, threat surfaces, and protected data pipelines. It combines established security practices with concerns that arise specifically when AI capabilities become part of an engineering workflow.

- A personal portfolio centered on secure data and ML engineering
- Technical articles that record security ideas and engineering viewpoints
- Examination of conventional and AI-specific attack surfaces
- Material addressing prompt injection risks
- Coverage of token authentication strategies
- Guidance and discussion around secure data and AI pipelines
- A browser-accessible web presentation
- Practical security considerations for systems involving data, models, and prompts

## Installation

```bash
git clone https://github.com/reedjordanvrb4237/0xcarnemuerta-security-hub.git
cd REPO
```

This HTML portfolio can be opened through a local static server or accessed from the project directory. For local development, start any static web server installed on your machine and browse to the URL it reports.

## Using the Portfolio

Common ways to work with the project include:

1. Visit the published site in a web browser.
2. Explore its portfolio areas and review the security-oriented data and ML work.
3. Read posts about AI security, prompt injection, authentication, and related threat surfaces.
4. Clone the repository to inspect or modify the site locally.
5. Serve the project with a static web server while developing changes.

Python provides a quick option for local hosting:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/` after starting the server.
